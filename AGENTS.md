# StoryMotion

For any new website or page with motion or a story:

- Decide the narrative level first (full / one scene / none), then follow `skills/scroll-narrative/SKILL.md` for the story.
- Any animation → `skills/web-motion/SKILL.md` (code in `skills/web-motion/references/recipes.md`, React / Next / Astro in `references/frameworks.md`, runtime in `skills/web-motion/assets/`).

Codex plugins have no slash commands; the `/story-page` command exists only in Claude Code and Gemini CLI. Ask in words instead ("build a site about …").
