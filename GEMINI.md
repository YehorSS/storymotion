# StoryMotion

When the task is a website or page that should animate or tell a story:

- Animation of any kind → read and follow `skills/web-motion/SKILL.md` (code in `skills/web-motion/references/recipes.md`).
- Narrative / scrollytelling / "not a boring catalog" page → read and follow `skills/scroll-narrative/SKILL.md`, start from `skills/scroll-narrative/templates/index.html`.

Paths are relative to this extension's folder.
